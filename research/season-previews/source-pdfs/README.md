# Season Preview Source PDFs

Upload season-preview source PDFs to this folder.

Examples: season magazines, annual guides, preview books, team/league guides, and other long-form preseason reference material.

These files are raw source material only. They are not part of the canonical Betting Edge Research Library and do not create or upgrade a BET by themselves. After upload, sources should be reviewed and indexed into the Season Previews manifest/library before runtime use.

Because this repository is public, only commit PDFs you are permitted to redistribute publicly.
