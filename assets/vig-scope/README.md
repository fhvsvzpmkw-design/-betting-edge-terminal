# VIG Scope meter assets

This directory is the canonical asset location for the VIG Scope meter-state visuals. State filenames use `vig-<heat>-<pressure>-<agreement>.jpg`, where heat is `low|medium|high`, pressure is `adverse|neutral|favorable`, and agreement is `low|high`, for 18 total meter combinations.

The VIG Scope visual is presentation only: the meters describe market conditions and do not independently authorize a BET. BET celebration assets are separate from these 18 meter states.
