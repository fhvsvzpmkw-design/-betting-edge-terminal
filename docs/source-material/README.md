# Source Material

This directory contains durable, human-readable source material used to inform Betting Edge research and design.

## Billy Walters — *Gambler*, Chapters 21–22

- [Clean verified transcription](gambler-chapters-21-22-clean-transcription.md)
- [Transcription verification report](gambler-transcription-verification-report.md)

### Provenance

The transcription covers chapter 21, “Master Class,” and chapter 22, “Advanced Master Class,” book pages 232–274. It was produced from user-supplied photographs and scans of a lawfully owned copy. Missing pages 236–237 and a clearer replacement image for page 245 were incorporated during reconciliation.

### Authority and verification

The clean transcription is the repository’s machine-readable document of truth for these supplied chapters. The photographed book pages remain the controlling evidence if a discrepancy is discovered.

Every supplied page received manual visual reconciliation. End-of-line typesetting hyphenation was normalized for readability. Apparent source wording or printing errors were preserved rather than silently corrected.

The verification report separates the initial automated disposition from the final manual result and records the scope of numerical and tabular checking.

### Operational boundary

This material is research evidence, not executable policy. It does not independently change the Betting Edge runner, production contract, pricing rules, staking rules, or report behavior.

Any operational adoption must occur in a separate derived-analysis document and then through the repository’s normal contract and acceptance process. Derived documents should cite the relevant book page and must not modify this transcription to fit an implementation.

### Maintenance rule

If a later comparison identifies a transcription discrepancy:

1. confirm it against the photographed source;
2. correct the transcription in a narrow, reviewable change;
3. update the verification report with the affected page and reason;
4. preserve the correction in Git history.
