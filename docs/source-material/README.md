# Source Material

This directory contains durable, human-readable source material used to inform Betting Edge research and design.

## Billy Walters — *Gambler*, Chapters 21–22

- [Clean verified transcription](gambler-chapters-21-22-clean-transcription.md)
- [Transcription verification report](gambler-transcription-verification-report.md)

### Provenance

The transcription covers chapter 21, “Master Class,” and chapter 22, “Advanced Master Class,” book pages 232–274. It was produced from user-supplied photographs and scans of a lawfully owned copy. Missing pages 236–237 and a clearer replacement image for page 245 were incorporated during reconciliation.

### Authority and verification

The clean transcription is the repository’s machine-readable document of truth for these supplied chapters. The photographed book pages remain the controlling evidence if a discrepancy is discovered.

Every supplied page received manual visual reconciliation. End-of-line typesetting hyphenation was normalized for readability. Apparent source wording or printing errors were preserved rather than silently corrected.

The verification report separates the initial automated disposition from the final manual result and records the scope of numerical and tabular checking.

## Police Quest / Jesse Bains reference pack

- [Police Quest series reference index](police-quest-series-reference-index.md)
- [Jesse Bains / Death Angel canon and language guide](jesse-bains-canon-language-guide.md)

The Police Quest material is maintained as a source map and derived character guide rather than a repository copy of third-party manuals or transcripts. PQ1 AGI/VGA and PQ2 are the controlling sources for Jesse Bains, the Death Angel, Hotel Delphoria and Jesse's gambling-world language. PQ3 is secondary Lytton/Bains legacy material. PQ4 and the SWAT branch are later procedural/style references and must not silently overwrite Jesse's late-1980s voice.

### Police Quest copyright boundary

Do not commit complete externally hosted manuals, hint books, transcripts or scans merely because they are available online. Preserve source URLs, provenance, concise factual notes, short necessary excerpts and our own derived rules. If the user later supplies a lawful copy directly for project use, handle that source under the same provenance and verification discipline used elsewhere in this directory.

### Operational boundary

This material is research evidence, not executable policy. It does not independently change the Betting Edge runner, production contract, pricing rules, staking rules, report behavior or issued recommendations.

Any operational adoption must occur in a separate derived-analysis document and then through the repository’s normal contract and acceptance process. Derived documents should cite their source material and must not rewrite source evidence to fit an implementation.

### Maintenance rule

If a later comparison identifies a source or transcription discrepancy:

1. confirm it against the controlling source;
2. correct the derived/transcribed material in a narrow, reviewable change;
3. record the affected source and reason;
4. preserve the correction in Git history.
