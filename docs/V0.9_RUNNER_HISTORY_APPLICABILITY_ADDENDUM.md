# Contract v0.9 Runner History Applicability — Staged Clarification

**Status:** STAGED — incorporate into Contract v0.9 before activation  
**Date:** 2026-08-15  
**Scope:** Clarifies the same-day runner-history behavior governed by Contract v0.9 Invariant 22.

## Required behavior

1. Permanent runner history is sourced from the durable report archive (`run-history.json` and immutable archived run payloads). Browser-local history may supplement it but must not supersede the durable archive.
2. A prior run may be hydrated into the active runner only when its `YYYY-MM-DD` exactly matches the active report's `YYYY-MM-DD`.
3. The five scheduled Vancouver run windows are:
   - 06:00 — `open`
   - 08:00 — `main`
   - 09:30 — `final_morning`
   - 15:15 — `evening`
   - 18:15 — `late`
4. On the current Vancouver betting day, a scheduled window becomes eligible only after that window's scheduled time has passed in `America/Vancouver`.
5. Once a scheduled window has passed, it remains eligible for the rest of that betting day when a valid archived run exists.
6. Future same-day windows must remain unavailable in both durable-archive hydration and browser-local supplementation.
7. The currently open run must not duplicate itself in prior history.
8. When multiple snapshots exist for one same-day run window, the newest valid snapshot for that slot is used. Reprice/manual snapshots therefore collapse under their originating run window rather than creating additional run-window buttons.
9. Historical report dates may expose all valid archived windows from that historical date because those windows are already in the past.
10. Future report dates must not hydrate prior-run history.

This clarification is not a Contract v0.9 activation by itself. Activation still requires the permanent archive path to produce live all-lane reports and pass the existing rollout acceptance checks.

1. The 15:15 report must be archived and indexed successfully.
2. The 18:15 report must be archived and indexed successfully.
3. Opening the 18:15 short link must make the valid 15:15 run available as same-day history while preserving the betting-day boundary and slot grouping rules above.

Until those live gates pass, Contract v0.8 remains the operational baseline and Contract v0.9 remains staged.
