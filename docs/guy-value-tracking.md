# Guy’s daily MoneyPuck value record

`data/characters/guy-laflame/value-ledger.json` holds the prospective ledger. `tools/track-guy-value.mjs` updates it after every successful shared game-intelligence collection and during the existing 03:00 Pacific recovery. The public record is shown on Guy’s Hotline and in VigScope Value, below the Graham comparison. Both views fetch saved data without caching on open/reload; Guy’s Refresh Rundown also reloads the record.

One daily selection must have a fair common cutoff. Before the first saved NHL start of a Pacific day, each successful collection retains its highest positive MoneyPuck full-game moneyline edge. The largest captured edge across those observations is the daily leader. Quotes must be observed within 75 minutes of recording; Pinnacle is a benchmark, not an offered tracking book. Exact ties retain the earlier candidate. The day freezes one minute before the first game, even if the next workflow runs later. Later games or price changes cannot replace a frozen pick. This measures the best price actually captured before that common cutoff, rather than a retrospectively chosen maximum across the whole night. It does not promise continuous price monitoring or an executable price at the cutoff.

Each observation retains the team, event and scheduled start, bookmaker, decimal price for exact calculations, displayed American odds, forecast, break-even probability, edge in percentage points, model/quote observation times and actual ledger recording time. The original observation receipts remain in the daily entry when the leader changes. The recorded odds are never repriced for settlement. Earlier source captures are not imported as Guy picks; installation after the cutoff records a skipped day.

Grading reuses the shared source grader’s exact-event verified final results. NHL full-game moneylines include overtime/shootouts. A win returns `priceDecimal - 1` units on one unit risk; a loss is `-1`. Net/ROI exclude pending and unresolved entries. With no settled picks, ROI is null and shown as a dash. Special or tied finals require settlement review. Scores and source links remain attached to the record. This is hypothetical value tracking, distinct from issued BET/LEAN/WAIT/PASS calls and customer wagers. MoneyPuck’s published probability can include market input.

Run `node --test tests/guy-value.test.mjs tests/guy-blue-line.test.mjs` to verify capture, cutoffs, no backfill, quote freshness, exact identities, outcomes, returns and display. `node tools/track-guy-value.mjs` advances the saved ledger at the current real clock. `node tools/build-guy-hotline.mjs --preview` refreshes only the static fallback; it does not rewrite published archives.
